# 资源检查

2026-09-29，在一台 Apple Silicon Mac（macOS 26.6.2）上检查 release 构建。使用 `vmmap` / `footprint` 的 physical footprint 口径；它不等于 `ps` 的 RSS，也不等于虚拟地址空间大小。

## 测量结果

| 场景 | 主进程占用 | 其他进程 / 说明 |
| --- | --- | --- |
| 0.2.3 以 `--background` 启动，未打开窗口 | 13.9 MiB，峰值 14.4 MiB | 输入监听和全局取色快捷键正常 |
| 0.2.2 页面压力检查开始 | 73.6 MiB | 此进程此前已经打开过多个工具 |
| 统计 → Portman → 取色，4 轮 | 75.8 MiB | 每轮回到取色页取样 |
| 同一路径，12 轮 | 76.1 MiB | 同上 |
| 同一路径，20 轮 | 78.3 MiB | 60 次页面切换，未见大幅累积 |
| 显示 Portman | 约 77 MiB | WebContent 30、Networking 5.5、GPU 15 MiB；独立 Python 后台约 20 MiB |

后台启动后每 2 秒采样一次，共 30 秒。跳过 `top` 首次样本后，15 个 CPU 样本均显示 0.0%；这是显示精度内的短时读数。页面检查前的 10 秒采样为 0.0%～0.5%。

离开 Portman 后，刚创建的 WebContent 和 Networking 进程退出；GPU 进程被系统保留复用，没有每轮新增一个常驻 GPU 进程。转发后台及 SSH 连接按设计继续运行。表中后台数字不包含每条 SSH 隧道各自的 worker / ssh 进程；实际总占用随连接数和流量变化。

## 结论与限制

这轮检查没有发现明显失控的 CPU 或大幅持续内存增长。不能把它解释为长期运行“绝无泄漏”，也不能把干净后台启动的 14 MiB 当作打开过全部页面之后的常驻上限。

`leaks` 对已安装进程报告 1,476 个可疑分配，共 95,856 字节（约 94 KiB），同时明确提示进程不可调试、读取受限。报告含系统 NSXPCConnection / Foundation 对象，缺乏完整分配栈，无法确认归因。本次没有改动正式应用的调试权限来强行读取它。

原进程的历史 footprint 峰值约 348 MiB，发生在本轮连续观察之前，无法仅凭该计数器判断触发操作。压力检查期间的采样值仍处于上表范围。系统图形缓存、打开新页面和取色时的瞬时分配不能与空闲常驻占用混为一谈。

资源采样期间没有生成输入测试文本、修改已有转发或清空真实数据。原始输出保留在本机 `output/verification/`，不随仓库公开。

## 0.3.0 滚轮反转复测

同日检查已安装的 0.3.0（build 8），开启垂直滚轮反转，打开过统计页和滚轮设置页。主进程 physical footprint 为 50.0 MiB；每 2 秒采样一次，共 16 次，跳过首次样本后 CPU 为 0.0%～0.3%，内存读数维持约 50 MiB。这是包含原有输入统计等功能的整个进程短时读数，不能单独归因于滚轮模块。进程历史 footprint 峰值为 302.4 MiB，不代表空闲常驻值。

滚轮模块没有定时轮询，只订阅滚轮事件与应用状态变化；关闭功能时移除滚轮监听。已验证旧 Scroll Reverser 启动时自动暂停、退出后自动恢复，以及开关和重启后的偏好保存。安装沿用原签名，辅助功能和输入监控授权保持有效，系统自然滚动设置未更改。

42 项专项检查通过，覆盖离散/连续事件、触控板与惯性事件保留、两轴独立反转、AppKit 读取、步长精度、偏好和权限/冲突处理；原有 86 项核心检查和 20 项取色检查通过。使用者已确认普通鼠标的实际滚动方向反转正常；触控板尚未做物理设备操作验证，其事件保留行为由构造事件测试覆盖。Magic Mouse 和连续滚动鼠标不在本版本的反转支持范围内。

## 0.4.0 防止休眠复测

开启防止休眠（屏幕常亮、直到关闭）和滚轮反转，已打开过统计及防休眠工具页。主进程 physical footprint 为 46.7 MiB，历史峰值 301.7 MiB；每 2 秒采样一次，共 16 次，跳过首次样本后的 15 次 CPU 均显示 0.0%，内存读数约 47 MiB。这是整个主进程在本次短时采样中的读数，不是防休眠模块的独立开销或长期保证。

防休眠模块持有一个原生电源断言；只有限时会话创建一次性到期计时器，界面展示结束时间而不逐秒刷新。没有另起 caffeinate 或辅助进程，也没有周期性模拟用户活动。系统活动列表确认开启时存在一个 MacToys 断言，手动关闭或退出后归零。

## 0.5.0 快捷面板复测

打开过统计和快捷面板，切换防休眠页后关闭窗口；输入统计、鼠标反转及屏幕防休眠保持开启。主进程 footprint 为 61 MB，历史峰值 357 MB；每 2 秒采样一次，共 16 次，跳过首次样本后 CPU 为 0.0%～0.1%，内存读数保持约 61 MB。这是短时空闲读数，不包含打开 Portman 时的 WebKit / Python 进程。

语言切换按操作更新界面，没有添加周期轮询；离开统计页或关闭弹窗会停用对应图表刷新。Portman 翻译只响应页面文字变化，不重载页面或修改映射。

## 复测

```sh
# 获取正在运行的正式应用 PID，然后手动代入以下命令
pgrep -x InputStats
vmmap -summary PID
footprint -p PID --noCategories --swapped
top -pid PID -l 16 -s 2 -stats pid,cpu,threads,mem
```

比较页面开关前后时，等待页面加载结束，并单独计入本应用新启动的 WebKit 进程。不要把其他应用的同名 WebKit 进程加进来。长时间压力与不同显示器 / 编辑器的行为仍需要持续验证。
