MacToys 0.7.3 adds automatic restart and restores tool settings after relaunch.

- Automatic restart is enabled by default. A lightweight user agent watches for app exits and backs off after repeated failures. Turn it off in Settings before quitting completely.
- Mouse wheel reversal and Keep Awake are on by default. Manual choices persist. Timed Keep Awake sessions resume with their original deadline.
- Input Stats now creates, updates, and releases accessibility observers on their notification thread, and drops stale callbacks after switching apps or sessions.
- Updates temporarily suspend supervision so the app can save notes and statistics before being replaced.
- Daily backups can save data to a configured private GitHub repository, with conflict protection.
- Portman recovers from stale macOS user contexts while preserving saved forwards. Concurrent readers follow a replacement daemon after a connection reset; mutations are never replayed automatically.

This build does not change existing macOS permissions or SSH configuration.
