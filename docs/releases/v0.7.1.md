MacToys now has self-contained installers for macOS 14+.

- **arm64**: Apple Silicon (M1 or newer).
- **x86_64**: Intel Macs.
- Includes Python and Portman, plus the offline Markdown editor. No Xcode, Homebrew, Python, pip, or Node.js installation is needed.
- Drag MacToys to Applications. A first-launch guide explains the permissions for Input Stats and Scroll Reversal.
- Fix a Portman worker crash when SSH exits before its parent closes the input pipe.
- Includes Todo, Notes, long-term goals, input statistics, port forwarding, color picking, mouse wheel reversal, Keep Awake, and manual private GitHub backups.

**Not notarized:** this release uses an ad-hoc signature. After trying to open it, macOS may require **System Settings → Privacy & Security → Open Anyway**. Download only from this repository. Managed Macs may not permit this exception. Accessibility and requested Input Monitoring permissions still require user approval.

[Installation](https://github.com/kennymckormick/MacToys/blob/v0.7.1/docs/installing.md) · [安装说明](https://github.com/kennymckormick/MacToys/blob/v0.7.1/docs/installing.zh-CN.md)

已内置 Python 和 Portman，拖入「应用程序」即可安装。M 系列芯片请选择 arm64，Intel 请选择 x86_64。当前版本尚未通过 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性 → 仍要打开」中放行。输入统计和滚轮反转仍需手动授予系统权限。

Quit MacToys before updating. Existing user data stays in `~/Library/Application Support/InputStats`. Source-build users with an `InputStats.app` installation should follow the migration notes before replacing their app; a different signature can require reauthorization.

SHA-256 files and JSON build manifests accompany each DMG. The manifests record the exact source commit, architecture, and Python runtime.
