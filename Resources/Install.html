MacToys

macOS 14+ · Self-contained · Not notarized

Install

  1. Drag MacToys.app to Applications. Eject this disk image and open MacToys from Applications.
  2. This release is ad-hoc signed, without Apple notarization. If macOS blocks it, after trying to open it, go to System Settings → Privacy & Security → Open Anyway. Approve only if you trust the download. Managed Macs may not allow an exception.
  3. MacToys starts with its permission guide. Grant Accessibility and any requested Input Monitoring access for Input Stats and Scroll Reversal, then quit and reopen the app. Todos, Notes, Goals, Portman and Keep Awake do not require these permissions.

Python and Portman are included. No Xcode, Homebrew, pip or Node.js installation is needed. SSH tunnels still use your SSH hosts and credentials. Notes work offline.

Updating: Quit MacToys before replacing it. Your data stays in ~/Library/Application Support/InputStats. If you previously installed a source build as InputStats.app, keep using the source installer with the same signing identity, or back up first and migrate deliberately; do not keep two copies. Moving from a self-signed build to this release can require granting permissions again.

CLI: /Applications/MacToys.app/Contents/MacOS/portman -h

安装

  1. 将 MacToys.app 拖入 Applications（应用程序），推出磁盘映像，再从应用程序文件夹打开。
  2. 本版本尚未通过 Apple 公证。如果 macOS 阻止打开，在尝试打开后，前往系统设置 → 隐私与安全性 → 仍要打开，仅在信任下载来源时放行。受组织管理的 Mac 可能禁止此操作。
  3. 首次启动会显示权限说明。输入统计和滚轮反转需要辅助功能及系统请求的输入监控权限；授权后退出并重新打开应用。待办、笔记、目标、端口转发和防止休眠不需要这些权限。

已包含 Python 和 Portman，无需安装 Xcode、Homebrew、pip 或 Node.js。SSH 隧道仍需你自己的主机配置和凭证。笔记编辑器可离线使用。

升级：先退出再替换应用。数据保留在 ~/Library/Application Support/InputStats。如果以前通过源码安装为 InputStats.app，请继续使用原签名的源码安装器，或备份后再迁移，避免保留两份应用。切换签名可能需要重新授权。
