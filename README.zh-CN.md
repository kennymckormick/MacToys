# MacToys

[English](README.md) · **简体中文**

macOS 14+ 工具箱：待办清单、Markdown 笔记、长期目标、输入统计、端口转发、屏幕取色、鼠标滚轮反转、防止休眠，以及 GitHub 私有仓库备份。

## 菜单栏

- 笔记固定在小菜单中。在「设置 → 小菜单」中，可从待办、目标、统计、取色、滚轮和防休眠中再选择最多 3 个页签。
- 可指定每次点击菜单栏图标时打开的页签，初始默认为待办。
- 支持简体中文、英文及跟随系统语言，无需重启即可切换。

## Todo List · 待办清单

- 在小菜单或主窗口中添加、编辑、完成和删除待办。
- 展开已完成的待办可恢复任务，也可一键清除已完成项。
- 两处界面共用同一份清单，保存在本机，重启后仍可使用。

## Notes · 笔记

- 所见即所得编辑 Markdown，支持标题、加粗、斜体、列表、勾选项、引用、代码块、链接和表格。
- 可切换 Markdown 源码，并将单篇笔记导出为 `.md`。
- 多篇笔记独立保存标题与内容，在小菜单和主窗口中编辑，输入后自动保存到本机。
- 编辑器离线运行，不加载远程图片或嵌入 HTML。

## Long-term Goals · 长期目标

- 用「目标」和「当前状态」两个文本字段持续记录进展。
- 在主窗口添加、编辑和删除，也可把「目标」加入小菜单。
- 目标一直保留，直到手动删除。

## Cloud Sync · 云端同步

- 手动把待办、笔记、长期目标、输入计数、颜色和应用偏好备份到 GitHub 私有仓库。
- 在另一台 Mac 上恢复快照。恢复前自动备份本机数据；恢复采用替换，不自动合并。
- 使用细粒度访问令牌授权，令牌保存在 macOS 钥匙串中，无后台轮询。
- Portman 规则、SSH 密钥、系统权限、登录启动与正在运行的防休眠会话保留在本机。

[同步设置说明](docs/cloud-sync.md#简体中文)

## InputStats · 输入统计

- 统计字符和单词，分别记录键盘与语音输入。通过 Fn 识别听写，也可手动切换来源。
- 查看每小时输入量、近 7 天趋势和年度热力图。
- 在菜单栏查看今日计数，图表每 5 分钟刷新。
- 导出 CSV 或 JSON。计数保存在本机，不保存输入的原文。

## Portman · 端口转发

- 支持本机 TCP 转发、SSH 本地转发和反向转发。
- 通过 GUI 或 CLI 添加、修改、启停映射，两者共用后台。
- 使用已有的 SSH 别名和密钥，连接中断后自动重连。
- 关闭窗口后继续转发。

## Color Picker · 屏幕取色

- 使用 macOS 放大镜拾取屏幕颜色，支持自定义全局快捷键，默认为 **Control + Option + Command + C**。
- 复制 HEX、RGB 或 HSL，可设置取色后自动复制。
- 输入 HEX 色值，或使用系统颜色面板调整颜色。
- 保存最近颜色和收藏。

## Scroll Reversal · 滚轮反转

- 独立反转鼠标滚轮的垂直、水平滚动方向。
- 保留触控板滚动及惯性方向，Magic Mouse 等连续滚动设备保持原样。
- 从菜单栏快速开关，关闭窗口后继续生效。

## Keep Awake · 防止休眠

- 阻止闲置休眠，持续到手动关闭，或选择 15 分钟至 4 小时的时长。
- 可同时保持屏幕亮起，也可允许屏幕熄灭。
- 从菜单栏快速开关，开启时在工具图标旁显示圆点。退出 MacToys 后结束。
